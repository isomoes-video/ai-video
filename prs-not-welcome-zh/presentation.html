开放式问题：社区还剩下什么位置？

如果 agent 写完了大部分代码，PR 还承担什么社会功能？

获得

  • 更快的分诊与复现
  • 更稳定的质量边界
  • 维护者可控的上下文

失去

  • 通过 review 培养新维护者
  • 偶然发现与外部视角
  • 贡献者的归属感

结论：PR 不是消失，而是换了位置

未来的开源贡献，更像一条信任阶梯：

报告真实问题

参与高质量讨论

在 agent 生产线上协作

成为值得信任的维护者

代码可以被 agent 重写，但方向、判断和责任仍然需要一个社区。
