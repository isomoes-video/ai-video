中文标题：让 Claude 可靠操作电脑与浏览器的工程实践
English Title: Engineering Reliable Computer and Browser Use with Claude

Source: https://claude.com/blog/best-practices-for-computer-and-browser-use-with-claude

这个视频系统讲解了 Anthropic 工程团队总结的「让 Claude 真正可靠地操作计算机和浏览器」的实战经验。内容沿着六个主题展开：分辨率与坐标对齐、点击失败的系统化诊断、模型与思考努力的选择、Prompt Injection 的纵深防御、长会话的上下文管理，以及通过演示教 Claude 完成复杂工作流。

视频首先强调了影响最大的单点优化——把截图压到模型视觉上限以内，并给出 Sonnet 4.6、Opus 4.7、Haiku 4.5 各自的像素上限与推荐起点；随后讨论了文本与图像在消息中的顺序、坐标空间到屏幕像素的线性映射公式，以及 max API fit 算法。接着把点击失败拆成恒定偏移、近失、点错相似元素三类典型症状，分别给出根因和对策，并列出针对小目标的四条策略。

在模型选择部分，视频对比了三款模型的精度、推理深度与延迟特性，并给出一个反直觉结论：Opus 4.7 推荐默认使用 high 而非 max 思考努力。安全章节介绍了模型层、分类器层、红队评估的三层纵深防御，以及人工把关、最小授权、审计日志等工程实践。长会话部分提出缓存断点、滚动缓冲、压缩三层叠加方案。最后讲解了 Show, Don't Tell 演示范式的三种回放模式，并介绍了 Batch Tools 与 Advisor Tool 两个实验性功能。结尾收拢出六条可直接用作检查清单的关键要点。
