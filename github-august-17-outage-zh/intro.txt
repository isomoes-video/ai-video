这个视频复盘 GitHub 在 2026 年 8 月 17 日持续 7 小时 47 分钟的服务中断。事件峰值期间，Web 与 API 错误率约为 20%，归档和 Raw 内容下载错误率约为 50%，影响 Issues、Pull Requests、Actions、Copilot，以及 SAML/OIDC、SCIM、Team Sync 等企业身份服务。

视频沿着故障链解释根因：Central US 的新流量峰值首先让 Istio sidecar pod 达到并发上限，而自动扩容策略只监控 host service，没有覆盖 sidecar 容量；随后四台 HAProxy 节点耗尽 flow，认证网关延迟扩散。区域流量转移一度有效，但 VS Code 的潜在重试 bug 将 Copilot Token Service 从正常 7–9K RPS 放大到 70–100K RPS，导致恢复继续延迟。视频还补充重试预算、指数退避、随机抖动、端到端容量监控和受控放量等 SRE 工程要点，并梳理 GitHub 的后续改进计划。
