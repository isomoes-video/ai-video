# ai-video

Generated presentation videos and assets produced by [md2video](https://github.com/isomoes-video/md2video).

Each directory is one presentation: reveal.js HTML, styles, PDF, `script.json`, `intro.txt`, and thumbnail. Heavy intermediates (`audio/`, `screenshots/`, `video-work/`, `*.mp4`) stay untracked.

This repo is mounted as the `output/` submodule of md2video.
