md2video

把一份文稿，变成一支有声视频

v0.1.5 自我介绍

我是谁

我是一个 agent 友好的小工作流：给我一份 Markdown 或任意文稿，
我把它变成带中文解说的幻灯片视频。

  • 每个阶段一个 prompt，做完一步、审核一步，再决定要不要继续
  • 所有产物都收在同一个 output/<presentation-slug>/ 工作区里

仓库里有什么

prompts/ — 给 agent 的阶段指令

  • slide-prompt.md 生成 reveal.js 演示与解说稿
  • tts-prompt.md 按 script.json 逐页配音
  • combine-prompt.md 把 PDF 与音频合成视频
  • script2intro / thumbnail / upload 简介、封面、发布

scripts/ — 可独立运行的工具

  • tts_from_script.py CosyVoice / OpenAI TTS 配音
  • combine_video.py ffmpeg 视频装配
  • thumbnail_from_prompt.py Qwen-Image 封面生成
  • upload_bilibili.py 读取浏览器 cookie 直传 B 站

生成的作品不放在主仓库：output/ 是挂载 ai-video 仓库的 git 子模块，演示产物的历史都记在那边。

v0.1.5 带来了什么

Bilibili 上传阶段

新增 upload-prompt 与 upload_bilibili.py：登录态直接读取本地浏览器 cookie，标题简介取自 intro.txt、封面取自 thumbnail.png，发布前必先 --dry-run 预览。

看板封面预览

实时流水线看板的卡片上，现在可以直接预览 thumbnail 阶段生成的封面图，不用再去文件夹里翻。

intro.txt 公共链接

简介格式新增一行公开产出 URL，发布页可以直接带上演示工作区的可访问地址。

更整洁的历史

为重写后的 git 历史重新生成了 changelog，纯产物提交都归档到 ai-video 子模块的历史里。

怎么开始用我

  • 克隆仓库：git clone https://github.com/isomoes-video/md2video
  • 准备一份 source.md 或一段文字想法，交给你的 agent
  • 按阶段挑 prompt：先出片子，审核满意了，再配音、合成、发布

我不替你创作内容，
我只负责让内容开口说话。
