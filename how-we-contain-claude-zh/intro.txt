中文标题：我们如何在产品中"控制"Claude
English Title: How We Contain Claude Across Products

Source: https://www.anthropic.com/engineering/how-we-contain-claude

这个视频讲解 Anthropic 工程团队如何在自家三款产品中"控制"住越来越强大的 Claude——在保留它能力的同时，把它一旦出错或被滥用可能造成的破坏范围（blast radius）压到最小。视频先从核心理念讲起：一个能力要不要上线，取决于出问题的概率、破坏范围与价值三者的平衡；接着梳理需要防范的三类风险——用户滥用、模型失当、外部攻击者，以及与之对应的三层防御：确定性的环境层、概率性的模型层，以及外部内容层。

随后视频用三种具体的控制模式展开：claude.ai 的临时容器（gVisor 隔离、用完即毁）、Claude Code 的人在回路沙箱（审批疲劳的真实数据与 OS 级沙箱带来的改进），以及 Claude Cowork 的封闭虚拟机（六道隔离机制、智能体循环移出 VM 的架构演进，以及一次借已批准域名外泄的攻击与中间人代理修复）。视频还讨论了强隔离带来的 EDR 可见性悖论、对外部内容与 MCP 工具保持警惕的必要性，并展望了持久记忆投毒、多智能体信任升级、智能体身份等未解难题。最后总结出三条经验法则：先在环境层做控制再在模型层做引导、让隔离强度匹配用户的监督能力、慎用自研组件。
